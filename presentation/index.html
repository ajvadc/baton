Architecture 03 / 10

The 5-Stage Verifiable Handover Pipeline

A structured pipeline transforming raw activity into an approved, role-filtered handover.

Stage 01 • Connect
Multi-Source Ingestion & Masking
Ingests Markdown ADRs, meeting syncs, task CSVs, and GitHub repos. Masks secrets, API tokens, and PII before AI processing.
Stage 02 • Reconstruct
Structured Claims & Evidence Spans
Rebuilds decisions, ownership, risks, dependencies, and timeline. Links every claim to verbatim quotes.
Stage 03 • Verify
Gaps Become Questions
Uncertainty is highlighted, not guessed. Missing facts and conflicts turn into targeted questions for the leaver.
Stage 04 • Review Gate
Human Editorial Control
Tech lead checks, edits, and formally approves claims. All modifications create immutable audit entries.
Stage 05 • Handover & Receipt
Role-Based Views & Digital Sign-off
Filters content before rendering (Successor, Teammate, Manager). Incoming person signs receipt with SHA-256 seal.

Core Innovation 04 / 10

Never Guess Consensus: The 4 Evidence Statuses

Standard LLM summaries hallucinate an agreeable middle ground when documents disagree. Baton makes disagreement explicit.

🟢 VERIFIED
Multi-Source Proof
Claim is confirmed by authoritative documentation or 2+ independent agreeing source chunks.
🔵 INFERRED
Single Source Claim
Derived from casual chat or unconfirmed notes. Flagged for human reviewer corroboration.
🟡 CONFLICTING
Contradictory Evidence
Sources disagree (e.g. Task board says Person A owns service; chat says Person B). Both are shown!
🔴 MISSING
Explicit Knowledge Gap
Crucial expected fact (e.g. Stripe webhook key owner) not found. Automatically prompts the leaver.
Team AstraX • Epistemic Classification Transparent evidence linking eliminates hallucination risk

Technical Architecture 08 / 10

Stack, Security & Implementation Hardening

Built for high availability, zero cold starts, and strict access isolation.

Frontend Architecture
• Next.js 16 + React 19 + TypeScript: Fast edge rendering.
• Dual-Mode Fallback Store: Edge persistence ensures 100% of features run seamlessly on Vercel without external DB latency.
• Defensive Array Guards: Protected against malformed data with zero client crashes.
Backend Architecture
• Python FastAPI: REST API with modular routers for projects, claims, review, GitHub diffs, and bot webhooks.
• Zero-Dependency SQLite: Bypasses Windows DLL and OS lock issues with pure portable ACID transactions.
• Pre-Generation RBAC: Restricted text never reaches unauthorized summaries (Successor vs Observer).
